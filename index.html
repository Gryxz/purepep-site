PurePep · brand + storefront source

Research-grade peptides. Verified per lot.

This repository carries the canonical PurePep brand source: locked palette and type tokens, finalized logo lockups, the RETA vial label, design-system preview cards, and the storefront UI kit (eight prototype pages plus shared React components).

The prototypes are the visual contract. The forthcoming WordPress child theme and wp-sync CLI in this repo will port these surfaces to purepep.shop while preserving the locked palette, hairline borders, generous whitespace, and one-CTA discipline. Start with the brand README for content + visual rules.
